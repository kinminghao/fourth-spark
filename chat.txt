Here's the project overview:

Fourth Spark — AI Agent Platform
Monorepo (bun workspaces), two packages:

packages/server — Hono + Bun 后端
OpenCode 的 HTTP/SSE 代理层，把本地 OpenCode serve 进程的 API 包装成前端可消费的 REST + SSE 接口。

| 模块 | 职责 | |---|---| | lib/config.ts | 环境变量：OPENCODE_URL、WORKSPACE_DIR、PORT、FRONTEND_ORIGIN | | lib/opencode.ts | OpenCode HTTP client — session CRUD、prompt、messages、todos、status、SSE 事件流 | | routes/sessions.ts | /api/sessions — 创建/列表/详情/删除 session，发 prompt，abort，获取 messages/todos/status | | routes/events.ts | /api/sessions/:id/events — 按 sessionId 过滤的 SSE 代理，带 heartbeat | | routes/agents.ts | /api/agents — 列出可用 agent | | routes/health.ts | /api/health — 自身存活 + OpenCode 可达检测 | | middleware/ | CORS（锁定 Vite origin）、pino 结构化日志、全局错误处理（OpenCodeError 转 JSON） |

packages/web — React 19 + Vite 前端
React 19 + Zustand 状态管理
Tailwind CSS v4
react-markdown + rehype-highlight（消息渲染）
lucide-react 图标
架构要点
代理模式：前端 → Hono server → OpenCode serve 进程，server 层做 CORS/日志/错误处理/SSE 过滤
SSE 事件代理：OpenCode 只有一个全局 /event 流，server 按 sessionID 过滤后推给前端
Fire-and-forget prompt：prompt_async 异步发送，结果通过 SSE 事件流回传
Bun runtime：idleTimeout: 0 保持 SSE 长连接
